# Anatomy Poser: clinical ROM tool + gamified anatomy

## Context

Anatomy Poser (https://evanmydude.github.io/AnatomyPoser/, repo `~/Desktop/AnatomyPoser`, single file `src/App.jsx`, ~710 lines) is a 2D SVG articulated figure with coronal and sagittal rigs, CCD inverse kinematics, per-joint range-of-motion (ROM) clamping, muscle ellipses, and a slider panel. It deploys cleanly but is clunky and teaches little.

Owner decisions (2026-09-19):
- **Primary audience:** physical-therapy-style ROM reference (goniometer-like readouts, compare a measured angle to norms, share a measurement).
- **Secondary:** rich anatomy info delivered in a gamified way (quizzes on the figure, muscle/joint cards).
- **Clunky today:** posing the figure, navigating the panel, learning anything from it. Reading numbers is fine.
- **Constraints:** stay a static GitHub Pages site; localStorage for progress; URL hash for sharing; no backend, no accounts.
- **Sequencing:** Foundation (no visible change) -> Measure -> Learn -> Quiz. Each phase deploys on its own.

## What the code review found (drives Phase 0-1)

Posing bugs: no `onPointerCancel`/`onLostPointerCapture`, `onPointerLeave` kills drags, no `e.buttons` check (App.jsx:281-291, 360). No grab offset so bones "pop" to the cursor (94-105, 261-263). No pointerId tracking. Pose/Isolate is a hidden mode that hides the other tool's affordances (203, 343, 426). CCD chains include wrist/ankle so the hand flaps; equal joint weights so the lumbar spine sways when you wanted a neck tilt (77-92, 108-121). A T-pose puts both hands outside the 420x640 viewBox (356). No undo, no persistence.

Number bugs: knees show AT LIMIT at rest because neutral sits on a ROM boundary (29, 547). Readout lacks the `locked` branch the table has, so coronal ankles show "+0° AT LIMIT" (521-538 vs 548). Joint stats derived in three places. `focusJointId` ignores `selected` so the readout goes dim unless dragging (307). `focus = hovered || selected` makes hover override selection (228). Paired sliders have mirrored signs (uarmL [-50,180] vs uarmR [-180,50]) so "+45" means abduction on one side and adduction on the other.

Structure/perf: right half of the coronal rig is a hand-mirrored copy (`nW' = 180 - nW`, `rom' = [-hi,-lo]`); segment lengths duplicated across rigs; CHAINS re-encodes topology derivable from `parent`+`ik`; `solveCCD` runs full-skeleton FK inside its inner loop (30 FK passes per pointermove); entire SVG and panel re-render every frame and on every hover; `getScreenCTM` read per move; no memoized subcomponents; no tests despite the header claiming a "Node harness". A11y: stage unreachable by keyboard, Seg buttons carry no aria state, `C.faint` on panel ~3:1 contrast at 9-10.5px.

## Clinical norms (verified AAOS Neutral Zero values)

Shoulder flex 180 / ext 60 / abd 180 / add 50; elbow flex 150; wrist flex 80 / ext 70 / radial 20 / ulnar 30; hip flex 120 / ext 30 / abd 45 / add 30; knee flex 135-140; ankle dorsi 20 / plantar 50; cervical flex 45 / ext 45-60 / lateral 45; thoracolumbar flex 80 / ext 25 / lateral 35. Sources: F.A. Davis "Measurement of Joint Motion: A Guide to Goniometry" normative tables; goniometer.io AAOS chart. Rig values differ in spots (elbow 145, hip ext 20, ankle PF 45): align in Phase 0 and note it in the commit.

## Design

### 1. One source of truth: movement-centric norms

- `src/data/norms.js`: `NORMS[jointType][movement] = { plane, norm, src, limit?, alt? }`, `SOURCES`, `BANDS` (normal >= 90%, mild >= 75%, moderate >= 50%, severe), `bandFor(pct)`. `plane: null` movements (rotation, pronation) exist for muscle actions and quiz text only.
- Bone specs (`src/rig/bones.js`) declare `motion: { pos: "abduction", neg: "adduction" }` or `motion: null` (locked in this plane) instead of `rom`. `resolveRom(plane, spec)` derives `rom` at load, so `rigOf`, `boundsOf`, `solveCCD`, `aimJoint` keep consuming `rom` unchanged. Coronal right side is generated by `mirrorBone` from the left; segment lengths live once in a `SEGMENT_LEN` table. `CHAINS` derived by walking `parent` while `ik`; wrist/ankle excluded from IK chains; per-chain weights (head `{neck:1, spineUp:.5, spineLo:.3}`, arm `{farm:1, uarm:.7}`).
- `src/rig/describe.js`: `describeJoint(rig, angles, plane, id)` -> `{ type, side, label, movement, degrees, norm, limit, pct, deficit, band, clinical, atLimit, locked, rel, relLo, relHi }`; `describePose` memoized per render. Every readout, the goniometer arc, activation glow, quiz scoring, and the URL encoder consume this. `atLimit` is only true when the joint has moved to a boundary, and `locked` is handled here once (fixes knees and ankles). Inverse: `setJointMovement(id, movement, degrees)`.
- Delete `NOTE`/`noteFor`; `movementNote` derives "abduction / adduction" from `motion`.

### 2. Unified interaction (kills Pose/Isolate)

Always-on affordances on the figure:
- **Joint dots** at each ik bone's pivot: click selects and opens its card; drag rotates only that joint by angular delta from drag start (`rotateJointByDelta`, 8px dead zone at the pivot); double-click resets to neutral; `tabIndex=0 role="slider"` with `aria-valuetext` ("45 degrees abduction"), arrow keys nudge (Shift 5), Home/End min/max, 0 neutral, Esc deselect, `[`/`]` prev/next joint.
- **Bone segments**: click selects for anatomy info; drag past a 4px (8px touch) threshold rotates the proximal joint via existing `aimJoint` with a grab offset recorded on pointerdown so nothing pops.
- **Effector handles** (head, hands, feet): IK drag via weighted `solveCCD`, chains exclude wrist/ankle, iterations 10 -> 4 with FK hoisted out of the inner loop; double-click resets the chain.
- **Muscles**: click selects; drag rotates the bone's proximal joint.
- Shift while dragging snaps to 5°; on release angles round to 1° (all `nW` are integers so neutral-relative values stay integral).
- Selection persists across release and plane switches (`xxxR -> xxxL` when entering sagittal).
- Pointer plumbing in `useDragInteraction`: capture on the target element, no `onPointerLeave`, handle pointerup/pointercancel/lostpointercapture plus a window pointerup fallback, track pointerId, store position in a ref and solve once per `requestAnimationFrame`, cache `getScreenCTM` at pointerdown.
- Auto-fit: when any effector leaves the viewBox, expand the viewBox (memoized on `pos`) so handles never become ungrabbable.
- Undo/redo in the reducer: snapshot on DRAG_BEGIN, NUDGE (coalesced 500ms), RESET_*, SET_JOINT; transient SET_ANGLES during drag does not push. Cap 100. Cmd/Ctrl+Z, Shift+Cmd/Ctrl+Z.

### 3. Panel: tabs + context card

Desktop (panel 336px, sticky stage as today):
```
[ Front | Side ]        [ Bones | Muscles | Both | Activation ]   toolbar (aria-pressed groups)
[ Undo ] [ Redo ] [ Reset ] [ Share ] [ Save ]                     persistent action row
[ Pose | Measure | Learn | Quiz ]                                  tabs
JointCard for the selected joint: big number + direction word ("45° ABDUCTION"), norm, ROM bar
  with neutral tick, slider + numeric input, other-plane reading, reset, muscles that produce it
RegionGroups (Spine & neck / Left arm / Right arm / Left leg / Right leg), collapsed = one-line
  summary; selected joint's region auto-expands; row hover highlights the bone on the figure
Finger curl folded into the arm groups; footnote with sources + disclaimer
```
- Hover is stage-local (label chip only); the panel shows selection only. Empty card state explains the three affordances.
- Mobile (`max-width: 720px`): stage ~55vh, panel becomes a bottom sheet with peek (toolbar + compact JointCard) and expanded states, `translateY` transition disabled under `prefers-reduced-motion`. No library.

### 4. Measure tab (primary audience)

- Selected joint readout: movement, degrees, norm, % of normal, deficit, band chip, source tag.
- **Goniometer arc** (`AngleOverlay.jsx`) at the joint pivot: neutral ray, current ray, faint arc to the norm, degree label. Built from `pos[parent]`, `dir[parent] + neutralLocalOf(id)`, `dir[id]`.
- Numeric entry may exceed the rig limit (hypermobility): figure poses at `min(value, limit)`, record stores the true value, readout says "posed at rig limit 180°, measured 190°".
- Sagittal has a "Measuring: Left / Right" side toggle; coronal infers side from the bone id.
- **Record** writes `{ j, s, m, d }` to the sheet (localStorage `ap.v1.measurements`). Sheet table: Joint | Side | Movement | Measured | Norm | % | Band; L/R rows adjacent with an asymmetry column.
- **Pose to norm**, **Copy link** (clipboard in the click handler, toast with `aria-live`), **Print** (print stylesheet + `Summary` component: figure + sheet + sources + disclaimer). **Export** SVG/PNG of the stage including the arc (clone svg, drop `data-hit` nodes, serialize; PNG via 2x canvas).
- Presets in `data/presets.js` as URL strings: Neutral, T-pose, Sitting, Squat, Reach.

### 5. Learn tab (rich anatomy)

- `src/data/muscles.js`: one entry per muscle: `{ id, name, group, paired, origin, insertion, innervation?, actions: [{ joint, movement, role: "prime"|"assist" }], why, place: { bone, depth: "ant"|"post", cor, sag } }`. `muscleInstances(plane)` expands L/R with `off` negated; `musclePlace` keeps its math; posterior muscles dashed in front view. Target ~22 muscles so every representable movement has a prime mover (SCM, erector spinae, rectus abdominis, external oblique, deltoid, pec major, lats, biceps, triceps, brachioradialis, wrist flexors, wrist extensors, iliopsoas, glute max, glute med, adductors, quadriceps, hamstrings, gastroc/soleus, tibialis anterior).
- `src/data/joints.js`: per joint type name, kind, common restrictions, measurement tip. Agonists per movement derived from muscle actions.
- **Activation glow**: `activationMap(descs, instances)` is a pure function of the pose; prime movers brighten with `degrees / norm`, assists at half. "Activation" layer dims non-working muscles. One `<filter id="glow">`.
- MuscleCard (origin, insertion, actions linked to norms, why) and JointCard (movements with norms/sources, agonists, restrictions) for the current selection; hovering a muscle in the list highlights it on the figure.

### 6. Quiz tab (generated from data, no hand-authored bank)

| Type | Prompt | Surface | Scoring |
|---|---|---|---|
| tap-muscle | "Tap a muscle that flexes the elbow" | muscle hit layer | prime full, assist partial |
| pose-to | "Set the left hip to 90° flexion" | only that joint grabbable, then Check | ±5° full, ±10° half |
| rom-normal | figure posed to X; "Within normal?" | 4 band buttons | band match |
| name-muscle | one muscle glows | 4 buttons, distractors from same group | id match |
| which-plane | "Hip abduction is in which plane?" | 2 buttons | `NORMS[].plane` |

- Stable ids (`tap:elbow:flexion`). `Stage` takes `interaction` (`pose` | `pickMuscle` | `poseJoint` | `readonly`) instead of a mode string. Runner state machine idle -> prompt -> answered -> feedback -> next.
- `useProgress`: Leitner-lite in `ap.v1.quiz`, boxes 0-4 with intervals 0/1d/3d/7d/21d, daily streak, sessions of up to 10 (due first, then unseen). Mastery heat strip.

### 7. URL and storage

- Hash codec (`src/state/urlCodec.js`), sparse and keyed so adding a joint never breaks old links: `#1;p=c;c=uarmL:45,farmL:-30;s=thighL:-90;f=30;j=uarmL;l=b;m=hip.L.fl.95,kn.L.fl.110`. Neutral joints omitted, emitted in `URL_ORDER` for determinism. Decoder tolerant: unknown ids ignored, values clamped via `boundsOf`, missing version = 1. Excluded from URLs: names, dates, notes, quiz progress.
- `useUrlState`: decode once on mount (LOAD does not push history; URL beats localStorage), `history.replaceState` debounced 300ms and never during a drag.
- `src/state/storage.js`: namespaced JSON keys with try/catch: `ap.v1.poses`, `ap.v1.measurements`, `ap.v1.quiz`, `ap.v1.prefs`.

### 8. Module layout

```
src/
  App.jsx                     composition only (~100 lines)
  rig/  bones.js (specs with motion, SEGMENT_LEN, mirrorBone, ANCHOR, PELVIS_FRAME)
        kinematics.js (rigOf, clamp, solveCCD weighted + hoisted FK, aimJoint, rotateJointByDelta, chainFor, snap)
        rigs.js (RIGS, CHAINS derived, REGIONS, URL_ORDER, jointPos)
        describe.js (typeOf, sideOf, jointLabel, movementNote, describeJoint, describePose)
  data/ norms.js, muscles.js, joints.js, labels.js, presets.js, quiz.js
  state/ poseReducer.js, urlCodec.js, storage.js
  hooks/ usePose.js, useDragInteraction.js, useKeyboardPosing.js, useUrlState.js,
         useMeasurements.js, useProgress.js, useMediaQuery.js
  stage/ Stage.jsx, geometry.js (seg, musclePlace, boneWidth), BoneLayer.jsx, MuscleLayer.jsx,
         HitLayer.jsx, Handles.jsx, AngleOverlay.jsx, LabelChip.jsx
  panel/ Panel.jsx, Toolbar.jsx, ActionRow.jsx, Tabs, JointCard.jsx, RegionGroup.jsx, JointRow.jsx,
         PoseTab.jsx, MeasureTab.jsx, LearnTab.jsx, QuizTab.jsx, Summary.jsx, BottomSheet.jsx, Toast.jsx, ui.jsx
  styles/ tokens.css (C as custom properties), app.css (S + CSS as `ap-` classes)
```
Dependency direction: `data/*` and `rig/*` are pure (no React); `state/*` pure; hooks import data+rig+state; stage and panel get everything via props. `useReducer`, no state library.

Reducer shape: `{ plane, angles: { coronal, sagittal }, fingerCurl, selected, drag, history: { past, future }, layer, tab, side }`. Actions: SET_PLANE, SELECT, SET_LAYER, SET_TAB, DRAG_BEGIN, SET_ANGLES (transient), DRAG_END (snap + commit), SET_JOINT, SET_JOINT_MOVEMENT, NUDGE, RESET_JOINT, RESET_CHAIN, RESET_PLANE, SET_FINGER, UNDO, REDO, LOAD.

Perf: `BoneLayer`/`MuscleLayer`/`Handles` memoized on `pos`/`dir`/`focusId`; rows receive primitive props so an IK drag re-renders only affected rows; hover state lives in `Stage`; `musclePlace` computed once per muscle per frame. Imperative attribute writes during drag only if profiling on a throttled device still drops frames.

A11y: joint dots as keyboard sliders, handles as buttons, `:focus-visible` on SVG targets, `aria-pressed` segments with `role="group"`, `aria-live="polite"` announcing committed values on DRAG_END/NUDGE, 44px targets on narrow, lighten `faint` to ~#7a8a92.
